# Phase 2 - Card Processing Engine

## Objective

Process a detected card image through cropping, perspective correction, deskewing, enhancement, and quality validation.

## Scope

- Automatic cropping
- Perspective correction
- Deskewing
- Image enhancement
- Quality validation

## Exclusions

- OCR
- Business data extraction
- Duplicate detection
- Storage organization
- GUI implementation
- Continuous workflow automation

## Deliverables

- Processing pipeline
- Quality checks for processed images
- Tests for the processing stages

## Success Criteria

- Card images are normalized reliably.
- Low-quality outputs are rejected when necessary.
- The processing stage remains separate from text extraction and storage concerns.
