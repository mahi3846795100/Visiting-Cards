# Phase 7 - Front And Back Capture Workflow

## Objective

Automate the capture of the front and back of a visiting card with flip detection.

## Scope

- Automatic capture
- Flip detection
- Front and back sequencing
- Continuous card-level workflow

## Exclusions

- OCR improvements
- Business extraction logic
- Duplicate detection changes
- GUI implementation
- Storage redesign

## Deliverables

- Capture workflow controller
- State transitions for front and back capture
- Tests for workflow behavior

## Success Criteria

- The system can guide a complete two-sided card capture flow.
- State transitions remain predictable.
- The workflow is reliable without user micromanagement.
