# Phase 3 - OCR Engine

## Objective

Extract raw text and confidence scores from processed card images using OCR.

## Scope

- OCR integration
- Raw text extraction
- Confidence reporting
- OCR result normalization

## Exclusions

- Business information interpretation
- Duplicate detection
- Storage workflow
- GUI features
- Continuous capture logic

## Deliverables

- OCR service layer
- Result data structures
- OCR-focused tests

## Success Criteria

- Text is extracted locally from card images.
- Confidence values are preserved.
- OCR remains isolated from higher-level business parsing.
